# Website AVENO

Website HTML, CSS và JavaScript thuần gồm 6 trang. Không cần Node.js, npm hoặc build.

Chạy tại thư mục chứa index.html:

```powershell
python -m http.server 4173
```

Website chỉ dùng tiếng Anh, không có bộ chuyển ngôn ngữ. Biểu mẫu chưa hỗ trợ gửi trực tuyến; nút gửi tạm vô hiệu hóa. Email, tên miền và hệ thống nhận yêu cầu chờ bổ sung; số điện thoại công ty tạm ẩn.

Nội dung dựa trên AVENO_Website_Content_v2_Simplified.xlsx đi kèm bản bàn giao. Tài nguyên nằm trong assets; giấy phép font và Bootstrap Icons được giữ cùng tài nguyên.
